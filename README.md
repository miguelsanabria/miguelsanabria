Actualmente trabajo en proyectos de **salud digital** 🏥 y **odontología inteligente** 🦷, combinando diseño cuidadoso con tecnología de punta.

`Next.js 16` · `React 19` · `Tailwind v4` · `TypeScript` · `Railway`
