Soy desarrollador frontend con alma de diseñador. Me gusta construir cosas que se vean bien, funcionen mejor, y hagan sentir algo a quien las usa.

Actualmente trabajando en proyectos de **salud digital**, **odontología inteligente**, y herramientas web modernas donde el código no solo resuelve problemas — los hace desaparecer.

## 🛠️ Lo que manejo

- **Frontend:** React 19, Next.js 16, TypeScript, Tailwind CSS v4
- **UI/UX:** Interfaces limpias, glassmorphism, animaciones sutiles, responsive sin dolor
- **Herramientas:** Git, Figma, Material Symbols, Google Fonts
- **Deploy:** Railway, Vercel, Docker, standalone builds

## 🧪 Lo que hago

Proyectos full-stack ligeros, landing pages que convierten, dashboards médicos, y ecosistemas digitales donde la tecnología le gana al papel.

Me gusta:
- El código limpio y con propósito
- Las experiencias de usuario que se sienten premium
- Los logos en SVG, los colores bien elegidos, y los archivos bien ordenados

No me gusta:
- El CSS inline
- Los commits sin `type`
- Las reuniones sin orden del día
