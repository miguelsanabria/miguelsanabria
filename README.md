Soy **desarrollador frontend** de Tepatitlán, Jalisco. Me dedico a construir interfaces modernas, funcionales y bonitas — porque creo que el código bien escrito puede transformar experiencias.

Actualmente trabajo en proyectos de **salud digital** 🏥 y **odontología inteligente** 🦷, donde combino tecnología de punta con diseño cuidadoso para crear productos que realmente importan.

## 📂 Proyectos destacados

### 🦷 Odontología Avanzada
Landing page moderna para clínica dental con concepto de **Pasaporte Digital**. Stack: Next.js 16 + React 19 + Tailwind v4. Diseño con glassmorphism, animaciones por scroll, y despliegue optimizado en Railway con modo standalone.

### 🏥 Ecosistema de Salud Digital
Plataforma web para gestión de pacientes con identidad digital, historial clínico automatizado, y acompañamiento post-operatorio 24/7. Interfaces limpias, flujo intuitivo y código modular.

### 🧪 Proyectos personales
Explorando constantemente nuevas herramientas, patrones de diseño, y formas de hacer que el frontend sea más rápido, accesible y bonito.
